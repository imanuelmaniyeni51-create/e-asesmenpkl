Integrasi Database Google Sheets

Multi-Device Sync

Hubungkan aplikasi ini dengan Web App Google Apps Script agar Penguji 1 dan Penguji 2 dapat menginput nilai secara bersamaan dari HP/Laptop berbeda.

* Jika dikosongkan, aplikasi berjalan dalam Mode Simulasi (In-Memory) dengan data contoh siap uji.

Kode Backend Google Apps Script (Code.gs)
  1. Buka Google Sheets baru, klik menu Ekstensi > Apps Script.
  2. Hapus kode lama, lalu tempel (paste) kode di bawah ini dan klik Simpan.
  3. Klik Terapkan (Deploy) > Deployment baru > Aplikasi Web.
  4. Pilih Akses: Siapa saja (Anyone), lalu salin URL Web App ke kolom di atas.
